HTML

HTML asoslari

HTML (HyperText Markup Language) — sahifaning skeleti. U matn, rasm va boshqa elementlarni brauzerga qanday joylashtirishni aytadi.

1. Sahifa strukturasi

Har bir HTML fayl quyidagi asosiy qismlardan iborat bo'ladi:

<!DOCTYPE html>
<html lang="uz">
  <head>
    <title>Mening saytim</title>
  </head>
  <body>
    <h1>Salom, dunyo!</h1>
  </body>
</html>

2. Teglar va elementlar

Teg — burchakli qavslar ichidagi buyruq (<p>), element esa ochuvchi va yopuvchi teg orasidagi butun blok.

  • <h1>–<h6> — sarlavhalar, kattadan kichikkacha
  • <p> — matn abzatsi
  • <a href="..."> — havola
  • <img src="..."> — rasm, yopuvchi tegi yo'q
  • <div> va <span> — bo'sh konteynerlar

3. Atributlar

Atributlar elementga qo'shimcha ma'lumot beradi va ochuvchi teg ichida yoziladi:

<a href="https://example.com" target="_blank">
  Saytga o'tish
</a>

4. Ro'yxatlar va jadvallar

<ul>
  <li>Non</li>
  <li>Sut</li>
</ul>

<ul> — tartibsiz ro'yxat, <ol> — tartibli ro'yxat, ikkalasi ham <li> elementlaridan iborat bo'ladi.

5. Formalar

Foydalanuvchidan ma'lumot olish uchun <form> va uning ichidagi <input>, <button> kabi elementlar ishlatiladi.

💡 Maslahat: HTML mazmun (content) uchun, dizayn uchun CSS, harakat uchun JavaScript ishlatiladi — ularni aralashtirmang.

6. Semantik teglar

<header>, <nav>, <main>, <article>, <footer> kabi teglar sahifa qismlarining ma'nosini bildiradi va qidiruv tizimlari uchun ham foydali.

CSS

CSS asoslari

CSS (Cascading Style Sheets) — HTML elementlariga rang, o'lcham va joylashuv beradi. U sahifaning "kiyimi".

1. Selektorlar

h1 {
  color: navy;
}
.card {
  padding: 16px;
}
#header {
  background: #171a21;
}

Teg nomi, .klass yoki #id orqali elementni tanlab, unga stil beriladi.

2. Box model

Har bir element to'rtta qatlamdan iborat: content → padding → border → margin. Bu tushunchani bilmasdan layout qurish qiyin.

3. Flexbox bilan joylashtirish

.container {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 12px;
}

Flexbox elementlarni bir qatorda yoki ustunda tekis joylashtirish uchun eng ko'p ishlatiladigan usul.

4. Ranglar va o'lchov birliklari

  • px — qattiq piksel o'lcham
  • %, vw, vh — nisbiy o'lchamlar
  • rem — asosiy shrift o'lchamiga nisbatan
  • Rang: nom (red), hex (#e37933), yoki rgb()

5. Responsive dizayn

@media (max-width: 600px) {
  .card { flex-direction: column; }
}

Media query yordamida sayt turli ekran o'lchamlariga moslashadi — mobil, planshet, kompyuter.

💡 Maslahat: butun saytga bitta shrift oilasi va 4–5 ta rangdan iborat palitra tanlang — bu dizaynni izchil qiladi.

6. Grid layout

Murakkab, ikki o'lchamli joylashuvlar uchun display: grid flexbox'dan ko'ra qulayroq — ustun va qatorlarni bir vaqtda boshqarish imkonini beradi.

JavaScript

JavaScript asoslari

JavaScript sahifani "jonlantiradi" — tugma bosilganda, forma to'ldirilganda yoki ma'lumot o'zgarganda nima bo'lishini shu til belgilaydi.

1. O'zgaruvchilar

let ism = "Aziz";
const yosh = 25;
let faol = true;

let — qiymati o'zgarishi mumkin bo'lgan o'zgaruvchi, const — o'zgarmas qiymat.

2. Funksiyalar

function salomlash(ism) {
  return `Salom, ${ism}!`;
}

salomlash("Dunyo"); // "Salom, Dunyo!"

3. Shartlar va sikllar

if (yosh >= 18) {
  console.log("Kattasiz");
} else {
  console.log("Yoshsiz");
}

for (let i = 0; i < 5; i++) {
  console.log(i);
}

4. DOM bilan ishlash

DOM (Document Object Model) — HTML sahifaning JavaScript orqali boshqariladigan ko'rinishi:

const tugma = document.querySelector("button");
tugma.addEventListener("click", () => {
  alert("Bosildi!");
});

5. Massivlar va obyektlar

const mevalar = ["olma", "nok", "uzum"];
const foydalanuvchi = {
  ism: "Laylo",
  yosh: 22
};
💡 Maslahat: avval HTML va CSS'ni mustahkamlang — JavaScript ular ustiga qurilgani uchun DOM tushunchasi tezroq yotib qoladi.

6. Zamonaviy JS (ES6+)

Arrow function (() => {}), template literal (`${...}`) va let/const — bugungi kunda eng ko'p ishlatiladigan zamonaviy sintaksis.
